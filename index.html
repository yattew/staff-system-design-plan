WhatsApp • Erlang / BEAM Week 9

2M Connections per Box

35 engineers running 900M users. Lightweight BEAM actor processes (~2.5KB RAM) + FreeBSD kqueue kernel socket buffer tuning.

Grammarly • Common Lisp Week 26

Microsecond AST Rule Engine

Compiled Common Lisp on SBCL. Code-as-data homoiconicity enabled 10x faster grammar tree mutations with a fraction of Java/Python's memory footprint.

Discord • Go to Rust Week 4

Eliminating the GC Cliff

Go's memory allocator and GC passes caused 2-second CPU cache-thrashing latency spikes across millions of channels. Rust dropped P99 from 2,000ms to < 5ms.

Figma • Rust + Wasm Week 10

Multiplayer CRDTs at 60 FPS

Custom operational transformation/CRDT engine in Rust running in-browser via WebAssembly, synchronized over WebSockets with central Rust coordinators.

LMAX • Mechanical Sympathy Week 27

6M Trades/Sec Single-Thread

The Disruptor pattern: lock-free circular ring buffers with cache-line padding (64 bytes) to eliminate False Sharing on CPU L1/L2/L3 caches.

Stripe • Idempotency Engine Week 26

Zero Duplicate Charges

Two-tier idempotency: Redis lease locks at gateway + transactional database commits with immutable double-entry bookkeeping ledgers.
